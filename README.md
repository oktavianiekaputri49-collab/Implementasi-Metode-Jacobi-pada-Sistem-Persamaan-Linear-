# Implementasi-Metode-Jacobi-pada-Sistem-Persamaan-Linear-
Mini project metode numerik menggunakan Metode Jacobi untuk menyelesaikan Sistem Persamaan Linear (SPL) dengan 3 variabel secara iteratif menggunakan Microsoft Excel.  Dalam project ini dilakukan proses iterasi untuk mencari nilai X 1 ,X 2 ,X 3  hingga mencapai konvergensi berdasarkan batas error yang telah ditentukan.
